# Facebook ad images: group rides (2026-11)

Three ads for the OnMyLead App Install campaign, each in two sizes: feed (1080x1350) and story (1080x1920).

- `a`: Ride Together. Get Home Together.
- `b`: Know the second someone falls behind.
- `c`: No service? Your group still hears you.

`design/ad.html?v=a|b|c&f=feed|story` is the source. To render, put the fonts, logo and screenshots
from the project's shared folder (`onmylead/ads-group-rides/design/`) next to it and run `node render.cjs`.
